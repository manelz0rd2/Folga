# Política de segurança

O Folga lê metadados locais para medir o uso do armazenamento e só move itens para a lixeira depois de confirmação explícita.

Para comunicar uma vulnerabilidade, escreva para `emanuel.pereira.fraga@gmail.com` com o assunto `Segurança — Folga`. Evite publicar caminhos pessoais, nomes de arquivos, relatórios do computador ou provas de conceito destrutivas em uma issue pública.

O projeto ainda não oferece recompensas ou prazos formais de resposta, mas relatos reproduzíveis serão priorizados.
