# Contribuindo com o Folga

Relatos de problema e sugestões são bem-vindos. Inclua o sistema operacional, a versão do Folga, os passos para reproduzir e, quando possível, uma captura de tela sem dados pessoais.

Antes de enviar uma alteração:

```bash
pnpm install
pnpm test
```

Não inclua arquivos pessoais, inventários de disco, caches, `node_modules`, `src-tauri/target` ou instaladores gerados nos commits.
